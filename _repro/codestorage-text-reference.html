Getting Started with Code Storage

This guide walks you through setting up your first Code Storage instance, creating repositories programmatically, and integrating with your application.

Installation

Install the SDK for your preferred language:

# TypeScript / Node.js
npm install @code-storage/sdk

# Python
pip install code-storage

# Go
go get github.com/code-storage/go-sdk

Authentication

Code Storage uses API keys for authentication. Generate your key from the dashboard and set it as an environment variable: 

export CODE_STORAGE_KEY="cs_live_..."

Security Note

Never commit API keys to version control. Use environment variables or a secure secret management system in production.

Creating Your First Repository

Initialize a storage instance and create a repository with the following code: 

const { GitStorage } = require('@code-storage/sdk');

const store = new GitStorage({
  name: 'my-app',
  key: process.env.CODE_STORAGE_KEY
});

const repo = await store.createRepo({
  id: 'user-123-workspace',
  warmStorage: true
});

console.log('Repository URL:', repo.getRemoteURL());

Repository Configuration

When creating a repository, you can configure several options:

  • id — Unique identifier for the repository
  • warmStorage — Enable low-latency warm storage tier (default: true)
  • replicas — Number of replicas (1-5, default: 3)
  • region — Deployment region preference

Working with Files

Code Storage provides both Git-native operations and SDK convenience methods for file manipulation: 

// Write a file
await repo.writeFile('README.md', '# My Project', {
  branch: 'main',
  message: 'Initial commit'
});

// Read a file
const content = await repo.readFile('README.md');

// List files
const files = await repo.listFiles({ branch: 'main' });
